Ein Business-Dashboard für Kanzleien,
das im Haus bleibt.

KanzleiCockpit liest den Buchhaltungs-Export einer Kanzlei und macht daraus eine vollständige Übersicht über Umsatz, Mandanten, Anwälte, Kosten und Liquidität — plus auf Knopfdruck generierte Partner-Briefings als PDF. Geplant als kleine Anwendung, die ausschließlich im Kanzlei-Netzwerk läuft, ohne Cloud und ohne Internet-Verbindung.

Diese Seite ist ein UI-Mockup mit synthetischen Daten zur internen Bewertung — noch keine lauffähige Anwendung. Unten: Tour durch 14 geplante Screens.

Tour starten Wie es läuft
On-Premise

Läuft komplett im Kanzlei-Netzwerk. Keine Cloud, keine Telemetrie, keine Internet-Verbindung erforderlich. Firewall-Regel kann den Prozess vollständig vom Internet abkapseln.

Leichtgewichtig

Eine ausführbare Datei, lokale SQLite-Datenbank. Installation unter 5 Minuten, läuft auf einer normalen Workstation. Kein Server, kein Docker, keine zusätzliche Datenbank.

Universell

Versteht DATEV, Lexware Pro, Addison OneClick, Stotax FibuNet, SAP Business One oder Generic CSV / XLSX — gleicher Workflow, gleiche Auswertungen, gleiches Mapping-Gedächtnis.

Lokales LLM (optional)

Anbindung an Ollama, LM Studio oder llama.cpp für narrative Briefing-Texte und Frage-Antwort-Bedienung. Modelle laufen auf eigener Hardware — Mandantendaten gehen nicht an OpenAI o.ä.
